# Dataset expiry, physical cleanup and clean-host recovery

One real combined integration case passed with zero skips in 61.913 seconds.
The exact source snapshot, generated schema/source digest, executable hashes,
command and archived external fixture hashes are in
[the manifest](20261031T102121Z-external.json); unchanged raw output is in
[the test log](20261031T102121Z-external-test.txt).

The fixture uses a Source-installed typed Dataset, two native versioned-MinIO
writes and actual execution/task pins. Ordinary runtime-role CLI approval and
raw policy mutation are denied. Young roots and immediate first-observed
collection remain protected. The fixture imports historical timestamps only for
closed roots/producers and never retimes a live lease or a claimed candidate.

After explicit operator approval, expiration publishes a metadata-only head and
exact issued-object collection removes the observed old physical versions.
An externally created newer version at an approved key survives. Current typed
rows are checked again, and a new backup succeeds after original source cleanup.

An independently retained pre-expiry backup restores into a fresh database and
fresh storage with old credentials/workers fenced. The operator registers a new
cell, assigns the paused placement with its actual owner/fence, activates it and
issues fresh authority. Full typed old-snapshot and current-snapshot rows match. The restored target
accepts a new finite policy; both historical roots have sealed qualifications
matching the policy physical fingerprint and current incarnation, with exact
original qualified-member cardinality.
A different restore to the same restored S3 prefix, with a fresh filesystem
target, is rejected by permanent target custody; dispatch stays disabled in that
failed target and the first restored installation still reads exact rows.

This is functional retention/recovery evidence on one physical host. It does not
certify production retention duration, throughput, independent failure domains,
HA, recovery SLA or the final combined program revision. Earlier failing trials
remain preserved.
