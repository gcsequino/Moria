# Connector Secret custody and checkpoint proof

The real native registered Sync worker and isolated Python/Arrow guest used eight
operator-approved credentials against a fixed local HTTP provider and versioned
S3 Dataset storage. The final focused gate passed all seven subcases plus its
parent (8/8, zero skipped/cancelled, 130.99 seconds). This proves the bounded
replace/full profile; it does not complete N09 or certify production capacity.

The cases cover exact independent caller/service Secret.use and operator-only
custody; permanent fencing after a missed approval pulse; queued file-policy
denial without killing the worker; atomic typed Dataset/head/checkpoint/receipt
publication; a second semantic cursor window with independent native UID/string/
array row readback; reflected-material withholding; and revocation closing an
in-flight provider socket before any new head or cursor publication.

The current source passed full static quality and all nine artifact fingerprints
plus 81 native unit cases before the fixture-only overlay. `source.json` records
that immutable build and the exact final TypeScript overlay. The final overlay
also passes full static quality. All owned controllers, temporary directories and
dedicated scratch pools were absent after completion.

Preserved trials: trial005 passed before independent readback; trial006 exposed
an OS permission error when a nonprivileged reader reused the privileged engine's
private snapshot cache. Each standalone catalog harness now gets its own private
cache. Trial008 is the final complete readback proof. Trial007 was a command-array
indexing mistake before dispatching tests; its raw output remains in the external
proof directory. Earlier failures remain there as well.

The fixture waits for provider entry within the unchanged accepted 120-second
execution window. Its revocation-to-socket-close bound remains ten seconds.
Cleanup uses the already-installed Python signal API because the image has no
external `kill` binary, and always attempts every owned cleanup after an error.

Still required: advertised optional capabilities, other write modes and coverage,
HTTP page/retry/acknowledgement faults and supervisor-loss proofs, composed full
quality and current independent CI, and production-scale performance qualification.
