# Resume an accepted evaluation Agent identity after a transaction retry

An actual private service case failed with this captured sequence: Agent progress returned SQLSTATE 40001, the case retried, the repeated Agent invocation entered public retained replay, and the unfinished callback produced FUNCTION_OBSERVATION_INCOMPLETE. The case then failed while its lease was still valid, invalidating its children. The private retry diagnostic in retry-red records the exact stages. Lease expiry was not the first failure in that reproduction.

The case controller now resumes only the UUID of its already accepted Agent. The credential-bound SQL helper validates the live private case lease/current purpose, actor, actual parent delegation, accepted binding/context, resource, request key, normalized immutable case input hash, and the suite's accepted code/adapter/model pin. It does not accept caller-supplied authority state or require a newly deployed code release. The Rust path uses the existing current-purpose/source/model progress checks before continuing; terminal data still passes the original retained release gate. Ordinary case links now commit atomically with Agent acceptance; the existing service trigger remains authoritative. The initial lookup connection is released before admission/progress obtains another pool connection. Public Agent idempotent replay retains its existing withholding checks.

The production cohort built **all nine native artifacts** in **26.571 seconds wall time**. Complete static checks plus all-nine source provenance verification and **99 actual native unit tests** passed, zero ignored. Its native source digest and executable hashes are retained. The later test overlays changed only TypeScript test fixtures, which are outside native inputs.

- The installed helper returned the exact accepted UUID, rejected a different case, and rejected an actual Agent-purpose private credential used against its parent case.

These checks prove stored-metadata predicates, not a live production metadata mutation.

- The actual pending-child progress path received one injected SQLSTATE 40001. No operation deadline, retry count, width, assertion, publication guard or authority check was relaxed.
