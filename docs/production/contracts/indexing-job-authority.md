# Accepted indexing job authority

An ordinary credential can accept a bounded indexing build while it is valid. `runtime_indexing_delegations` pins that build's original credential hash, environment/principal/application, immutable definition/context/source pin/epochs/incarnation/deadline, and minimal accepted capabilities. Acceptance never extends the ordinary credential TTL and never replaces its hash.

The proof has the common accepted-origin fields plus `purpose: "indexing"`, `allowedSources: [canonicalSourceResource]` and `indexTarget: canonicalTargetResource`. Accepted operations are source `read`, target `index`, and filesystem `read` only when originally present. Accepted markings equal the build's complete declared markings. The shared current-origin normalizer intersects these capabilities with current policy, checks original disable/provider/principal/application state, and ignores only the original credential's TTL. New grants do not broaden accepted work.

`indexing_check` uses this record for an accepted build. Exact current epochs, binding, source classification, instance incarnation and build deadline still apply. Unaccepted or retired definitions cannot ignore credential expiry. Automatic permanent indexing needs an explicitly registered service-origin profile; it cannot borrow an expired ordinary registration.

Private credentials require an actual live admitted indexing attempt. `runtime_indexing_session_issue(build, task, owner, fence, hash)` checks the real build/task lease and durable `indexing_attempts` row; `runtime_indexing_job_session_origin(hash)` rechecks those fences, status, incarnation and deadline on every resolution. No generic execution or fleet worker rows are manufactured. Ordinary, generic-job and indexing-private hash collisions fail. `io::Scope::active_session()` supplies the internal native session factory; public bearer authentication accepts only ordinary sessions.

An indexing private session can check only its canonical source's resource read authority. It cannot use raw filesystem access/content APIs, query an ObjectType as a Dataset alias, write a source Dataset, accept another job, or authorize another namespace. Physical indexing reads and private artifact output retain their distinct namespace guards and current before/after-transfer checks.

A valid Dataset publication can outlive an older index registration. If that registration has an allowlisted stale authorization condition, publication records an immutable `indexing_blocked_intents` row with the exact target/binding/source revision/metadata/snapshot and safe error. It creates no accepted delegation or runnable task. Unknown database errors still abort. A fresh authorized registration against the same head creates a new build; the old blocked intent remains visible as serving lag.

Real native tests fix ordinary expiry before acceptance, stop a real coordinator, cross the actual wall-clock TTL, verify ordinary/public denial with continued scoped indexing, exercise current revocation/fence/incarnation controls, and resume to activation. Capacity certification remains open until the complete measured pipeline and protected serving workload pass.
