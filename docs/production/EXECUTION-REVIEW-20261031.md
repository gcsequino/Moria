## Verified boundaries

Evaluation trial008 retained a strict failure when one sealed Function could not publish during the actual root lost-acknowledgement scenario. Publication now retries only PostgreSQL serialization/deadlock aborts, at most four attempts inside the original database-derived deadline. It never reruns guest code or retries an uncertain commit. Safe terminal cause/SQLSTATE diagnostics and real PostgreSQL abort/exhaustion tests are staged for the next artifact. The fixture guest also polls an accepted child after the API's bounded 25-second wait instead of treating an active response as terminal. The failed trial is preserved; these changes require fresh qualification.

Two targeted Agent regressions passed against the same immutable native artifact: [model/tool callbacks](../benchmarks/native-agent-model-targeted-20261031-trial-003-passed.tap) and [accepted Secret approval generation](../benchmarks/native-agent-model-targeted-20261031-trial-004-passed.tap). The former exercises protected read classification, model usage, committed tool effects and retained receipt source authorization. The latter proves private material labels before code, missing-use denial, missed approval disable/reenable rejection without provider dispatch, and fresh reapproval. Each selects one subtest and explicitly skips eighteen others; these passes do not supersede the failed combined trials or qualify the remaining factories.

Actual PostgreSQL diagnostics also exposed a model guard that paused protected work while awaiting its own execution fence on another connection. The guard now polls independently alongside that work, and completion transactions acquire the execution fence before current source and receipt checks. The targeted model/tool pass exercises this correction; the busy-class admission ordering and full combined regression remain required.

The [full callback regression](../benchmarks/native-observation-journal-20261030-trial-002-passed.tap) passed 48 tests with zero skips. A real protected read blocked before durable observation completion, followed by native worker `SIGKILL`, left a pending journal and withheld results/events after rollback and clearance change. There was no receipt or transparent user-code retry. Callback cancellation and revocation remained fail-closed.

The [generic ancestry regression](../benchmarks/native-observation-journal-20261030-trial-010-passed.tap) passed 17 tests with zero skips. It covers an actual Agent observing a failed private Function child, parent cancellation stopping the child within ten seconds, and retained secondary Action outcome replay. This is ordinary accepted-session evidence; it does not qualify the separate service-purpose composition above.

The [service generation regression](../benchmarks/native-observation-journal-20261030-trial-011-passed.tap) passed 10 tests with zero skips. Actual authority and target registrations were disabled and reenabling occurred before any intermediate authority check. Captured generations rejected the old private capability and binding even when supplied with current epochs. Caller changes to captured generations were rejected.

The [initial engine proof](../benchmarks/native-pipelines-20261030-trial-026-passed.tap) passed eight tests with zero skips. It includes real bounded DuckDB/Arrow/Parquet/Iceberg interoperability, three input Datasets, grouped outputs, exact UID/scalar-array readback, actual hard spill exhaustion, protected cleanup and slot reuse. Its accepted database deadlines remained 120 seconds. General Sync checkpoint, cancellation and lost-ack fault coverage remains a separate required gate.

## Default caller boundary

`apps/local/src/runtime.ts` selects the persistent native launcher before constructing the legacy workspace, ObjectService, Functions or Jobs. Production rejects the explicit legacy runtime/custom execution-factory option. Operational CLI callers use persistent authenticated native HTTP; worker entrypoints replace the CLI process with the registered native binary. Guest JavaScript/Python runs as the isolated published program, with no host actor, credentials, sockets or arbitrary endpoint authority.

Retained TypeScript bootstrap, compiler, SDK serialization, UI, security administration and OIDC verification are control/client boundaries. Their continued presence does not imply a Node worker on the operational path. Explicit development compatibility services still require continued regression coverage so they cannot become a silent production fallback.

Fresh combined runtime/library/schema/TypeScript gates, actual local-instance integration and the remaining findings above are required before closing the corresponding program rows. Every failed trial remains separate from later passing evidence.
